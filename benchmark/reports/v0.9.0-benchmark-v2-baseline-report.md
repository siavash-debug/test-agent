## Timing Methodology

Per V2 methodology:
1. Pipeline loaded once via `generate.load_pipeline()`
2. Warm-up: 2 non-timed generations across all prompts
3. For each prompt:
   - `torch.cuda.synchronize()` before timer
   - `time.perf_counter()` start
   - `pipe()` generation (production pipeline)
   - `torch.cuda.synchronize()` after generation
   - `time.perf_counter()` stop
   - Image saved AFTER timing stops
   - Metadata written AFTER timing stops
